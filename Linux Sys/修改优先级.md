## chrt
查看调整进程和线程的调度策略和优先级
```
chrt -p <pid>
```
常见调度策略
SCHED_OTHER: 默认的 Linux 调度策略，适用于大多数普通进程。
SCHED_FIFO: 先进先出调度策略，适用于实时任务。
SCHED_RR: 轮转调度策略，适用于实时任务。
SCHED_BATCH: 批处理调度策略，适用于批处理任务。
SCHED_IDLE: 空闲调度策略，适用于非常低优先级的任务。
SCHED_DEADLINE: 截止时间调度策略，适用于需要在特定时间内完成的任务

### 修改策略和优先级
查看策略支持的优先级
```
chrt -m
```
SCHED_OTHER min/max priority	: 0/0
SCHED_FIFO min/max priority	: 1/99
SCHED_RR min/max priority	: 1/99
SCHED_BATCH min/max priority	: 0/0
SCHED_IDLE min/max priority	: 0/0
SCHED_DEADLINE min/max priority	: 0/0
修改
```
chrt <策略> -p <优先级> <pid> 
```
策略
```
-b, --batch          set policy to SCHED_BATCH
-d, --deadline       set policy to SCHED_DEADLINE
-f, --fifo           set policy to SCHED_FIFO
-i, --idle           set policy to SCHED_IDLE
-o, --other          set policy to SCHED_OTHER
-r, --rr             set policy to SCHED_RR (default)
```

## 修改中断绑定CPU
/proc/irq/<中断号>/smp_affinity
下面是CPU号举例
```
            Binary          Hex   
CPU 0       00000001         1   
CPU 1       00000010         2  
CPU 2       00000100         4  
CPU 3       00001000         8  
```
例如绑定到CPU 2上
```
echo 4 > /proc/irq/<中断号>/smp_affinity
```
绑定到CPU 0和CPU 1上，就是0x1 + 0x2 = 0x3
```
echo 3 > /proc/irq/<中断号>/smp_affinity
```
